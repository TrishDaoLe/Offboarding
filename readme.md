# Offboarding-HTTPTrigger1 Summary
Executes initial offboarding automation triggered by Jira

## Steps
1. Connect to Jira
2. Get Details from ticket
3. Validate Inputs
4. Disable Account
5. Revoke Sign In Sessions
7. Revoke Authentication Methods
8. Webex Phone Forwarding
9. Update Core Fields
10. Set Custom Security Attributes
11. Remove Groups
12. Covert to Shared Mailbox
13. Assign Mailbox Access
14. Assign OneDrive Access
15. Send Manager Email
16. Create Sub-task Ticket
